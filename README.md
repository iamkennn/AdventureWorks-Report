Project Overview
Developed an interactive Power BI business intelligence dashboard using the AdventureWorks dataset to analyze sales performance, profitability, orders, returns, and product trends. The report transforms raw business data into actionable insights through interactive visualizations and KPI tracking.

Key Features

Built executive-level KPIs for Revenue, Profit, Orders, and Return Rate.

Analyzed revenue trends over time to identify changes in overall business performance.

Compared orders across product categories to understand category-level demand.

Created a Top 10 Products analysis using orders, revenue, and return rates.

Monitored monthly Revenue, Orders, and Returns, including comparisons with the previous month.

Identified the most ordered and most returned product types.

Added dedicated Map, Product Detail, Customer Detail, and Category Tooltip pages for deeper analysis.

Implemented interactive filtering and drill-down functionality to support exploratory analysis.
